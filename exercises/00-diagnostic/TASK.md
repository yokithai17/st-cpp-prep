# 00. Диагностика

Цель: выяснить текущий уровень и выбрать стартовый темп. Незнание — полезный результат диагностики. Ответы записывать в `answers.md`; для сомнения указать, что именно неизвестно. Начать с D1, остальные вопросы обсуждать последовательно.

Сначала объяснить код без подсказок. Не запускать фрагменты с подозрением на undefined behavior ради предсказания «вывода»: успешный запуск не доказывает корректность.

## D1. Время жизни

```cpp
#include <string>
#include <string_view>

std::string_view make_name() {
    std::string name = "spectral";
    return name;
}
```

1. Что хранит возвращаемый объект?
2. Корректно ли прочитать его символы после возврата функции? Почему?
3. Как изменить интерфейс, чтобы вызывающий код получил корректный результат с понятным владением?

## D2. Контейнер и ссылки

```cpp
#include <vector>

std::vector<int> values{1, 2};
int& first = values.front();
values.reserve(values.capacity() + 1);
// Можно ли теперь использовать first?
```

Объяснить reserve/resize, время жизни элементов и инвалидирование. Указать, что гарантирует стандарт и что здесь известно о reallocation.

## D3. Перемещение

```cpp
#include <string>
#include <utility>

const std::string source = "spectral";
std::string destination = std::move(source);
```

Что делает `std::move`? Какой тип получает выражение? Вызывается ли здесь move constructor `std::string`? Объяснить выбор, а не только назвать операцию.

## D4. Потоки

Два потока независимо выполняют `++counter` для одной обычной переменной `int`, без синхронизации. Что неверно? Как исправить? Достаточно ли `volatile`? Если атомики ещё не изучены, достаточно прямо это указать.

## D5. Кодовая задача

Написать функцию, находящую длину самого длинного непрерывного фрагмента массива целых чисел без повторяющихся значений. Объяснить подход, инвариант, время/память. Проверить пустой массив, все одинаковые значения и повторение за левой границей текущего окна. Целевой ориентир — 35–45 минут; превышение времени не считается провалом диагностики.

## Итог

После собственных ответов провести разбор: уверенная база / требуется повторение / ещё не изучалось. Не закрывать диагностику одним числом или сравнением с другими студентами. Первое практическое упражнение выбираем по обнаруженным пробелам; ожидаемый следующий шаг — `01-unique-fd`.
